# 本机验收方法

在项目目录运行 `python3 -B -m unittest discover -s tests -v`。自动化测试使用测试替身和本地模拟服务。实际客户端可单独验证以下三项。

| 项目 | 验收依据 |
|---|---|
| 推理 | 核对预期 JSON 字段和数值。 |
| 中文写作 | 核对交接文本是否覆盖目标、成果和验收要求。 |
| 文件生成 | 在任务工作区核对文件内容和 SHA-256。 |

原型验收中，这三类 Codex CLI 任务均通过。该结果仅覆盖当时测试过的任务。公开的 [结构化结果](live-probe-results.json) 为合成样例；完整验收方法见 [检查记录](acceptance-review.md)。
