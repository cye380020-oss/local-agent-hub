# 客户端接入依据

安装状态、可执行入口、模型配置与真实任务结果应分别记录。可通过应用的 Info.plist 查看公开安装信息，通过 CLI 帮助核对支持的选项。桌面界面上的模型名只能作为界面标签。

| 入口 | 验证方法 |
|---|---|
| Codex CLI | 检查非交互执行、工作区约束和登录状态，再用独立的小任务验证结果。 |
| DeepSeek Harness | 分别检查 Desktop 与 headless 的配置和能力。独立确认执行入口、有效模型及权限参数。 |
| 其他桌面客户端 | 获得用户许可后验证官方入口或文件交接，记录实际执行方式。 |

公开示例见 [结构化快照](final-state.json)。生成自己的验收记录时，原始配置、截图和任务历史应保存在私有工作区。
